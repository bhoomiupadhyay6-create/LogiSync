# LogiSync

LogiSync is a Python-based Windows desktop application that automates shipment tracking for businesses.

Instead of manually checking courier websites and updating Excel sheets, users simply select an Excel file containing shipment tracking numbers and click **Update**. LogiSync retrieves the latest shipment location and delivery status using courier APIs and automatically updates the spreadsheet.

## Features

* 📦 Automatic shipment tracking
* 📍 Real-time location updates
* ✅ Live shipment status updates
* 📊 Excel (.xlsx) integration
* 🔄 One-click update process
* 🖥️ Windows desktop application
* 🔌 REST API integration
* ⚡ Fast and lightweight

## Tech Stack

* Python
* CustomTkinter
* Pandas
* OpenPyXL
* Requests
* PyInstaller

## Project Goal

To simplify logistics tracking by eliminating repetitive manual updates and providing businesses with an efficient, one-click solution for maintaining shipment information in Excel.
